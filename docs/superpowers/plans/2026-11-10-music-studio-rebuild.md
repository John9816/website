# PC / H5 音乐工作区重构

用户授权单 agent 自主设计、实现、推送、部署。只处理网站 PC / H5，必要时调整后端；保留两种明暗模式与现有站点登录。

## 设计决定

- 独立音乐工作区：PC 固定侧栏 + 单行搜索工具栏 + 内容舞台 + 常驻播放器。H5 单行标题栏 + 原生式底部导航 + 紧凑播放器；其他视图进入可访问菜单。
- 发现页以唱片封面构成横向展示，主操作是收听与漫游。曲库、搜索、详情统一歌曲行和清晰的操作反馈。
- 色彩：午夜蓝 #101520、石板蓝 #1a2230、雾蓝 #9bb4ff、纸白 #f4f6fb、墨蓝 #172233、辅助灰 #7f8da3。亮色强调 #395fbb；仅白天/黑夜两种主题。显示字体沿用 bankUbuntu/中文系统字，正文系统字体，时间用等宽数字。
- 动效集中在封面、正在播放标识和小范围状态变化；避免多层装饰卡片，支持 reduced motion。
- 主导航、搜索和页面内容分离；返回与键盘保持可用。H5 不复用横向压缩的桌面表格。

## 性能与正确性

- 目录请求增加有 TTL、数量和总大小上限的内存缓存；相同请求合并，独立取消订阅，账号变化清空。认证/播放票据/漫游序列不缓存。
- 只预取即将访问的数据；下一首播放地址有界预取，并尊重节流网络设置。
- 拆分浏览控制与播放时钟上下文，列表不随 timeupdate 重绘。
- 收藏即时更新，失败回滚；跨视图状态同步；个人曲库变更使缓存失效。
- 实测重复访问的请求数量、缓存延迟和主操作可见反馈。外部网络首次请求不能承诺物理零延迟。

## 验证与交付

先覆盖缓存并发/取消/过期/隔离等关键行为，再实现；检查 PC 1440/1024、H5 390/320 的明暗主题、导航、搜索、播放、歌词、歌手、漫游、歌单和键盘。
生产构建、现有回归、真实上游和线上 PC/H5 验证后推送部署。保留无关部署文件改动；使用版本目录、备份、校验与回滚。
