# 学城文档集成设计

用户已选择新增“学城文档”模块，并授权集成及部署到现有 ECS。

- 入口 `/editor/`，保留上游文档树、编辑器、模板、收藏、文本技能和公开分享；网站主导航和管理菜单提供入口。
- 前端源码来自 John9816/xuecheng-editor 的 e72dc77e1a13c181cdde43bf818059527d50b846，随 website 构建。样式限制在模块容器中。
- 复用 website 的登录及刷新令牌客户端。除显式公开分享和随机文件 URL 外，所有编辑器接口通过既有后端 `/api/user/me` 验证身份；文档和模板按 user id 分目录。
- API `/editor/api/*` 由现有 ECS Node 服务处理，使用 Node 内置模块。持久目录由 `EDITOR_DATA_DIR` 指定，生产为 `/opt/website/shared/xuecheng`；不依赖发布目录，不改现有 Java API 或数据库。
- MCP 服务管理仅 ADMIN 且 canManageSystemConfig 开放。stdio 子进程不继承网站密钥，生产降权到 nobody。
- 上游自动保存需绑定文档 id、序列化写入，并在切换文档时正确保留待保存内容。服务端读取损坏存储应报错而不能静默清空。
- 验证包括鉴权、两个用户隔离、CRUD、模板、分享启停、上传、持久化、MCP 权限、前端真实浏览器与生产健康检查。
- 发布新目录，复用当前后端制品；保留旧版本和回滚记录。现有音乐下载部署文件中的用户改动不修改、不自动发布。
