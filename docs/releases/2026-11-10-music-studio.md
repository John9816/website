# PC / H5 音乐工作区

## 体验

- PC 固定功能侧栏、统一顶部搜索、唱片推荐舞台、底部播放器。
- H5 使用四项底部导航、移动歌曲行、紧凑播放器；菜单保留榜单、歌单、新歌、收藏和历史入口。
- 白天 / 黑夜两种主题，支持 320px 起的布局和减少动态效果偏好。
- Ctrl/Cmd+K 或 / 聚焦搜索；播放器快捷键避让输入框、按钮和滑块。
- 歌曲、歌手、专辑和歌单搜索共用一个入口。歌手抽屉、专辑详情、歌词、漫游连续收听。
- 浏览和搜索不会改变已有播放队列。登录令牌续期保持播放，切换账号清理播放状态。
- 收藏在列表和播放器中同步即时反馈，失败回退，并发点击合并。

## 性能

只读目录使用账号隔离的内存缓存（默认 60 秒、推荐 45 秒，最多 120 条 / 8 MiB），合并并发请求并隔离取消操作。播放解析保留现有票据有效期约束；个人数据写入、认证与漫游推进不使用目录缓存。导航有界预取；节省流量 / 慢网时跳过下一首解析预取。歌词和播放时钟不会驱动浏览组件重新渲染。

缓存浏览器用例实测约 0–0.1 ms；服务器接口抽测首次搜索约 843 ms、缓存搜索约 12 ms。外部网络和上游首次响应不作零延迟保证。

## 验证和发布

- TypeScript 与 Vite 生产构建；46 项 Node 测试。
- PC 1440/1024、H5 390/320，明暗 8 种组合：搜索、队列保持、收藏、歌手歌曲/专辑、漫游重试与自动续播、主题切换、移动菜单、播放器避让导航。
- TTML / 逐字歌词、键盘搜索建议、蓝牙歌词、异步竞态、播放时钟隔离。
- 缓存合并、独立取消、过期、大小限制、账号切换、登录续期。
- 服务器真实接口验证：歌词、歌手作品、播放流、歌单导入/同步和跨账号访问隔离。
